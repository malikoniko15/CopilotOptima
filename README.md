# AI Cost Tracker

**AI Cost Tracker** — это корпоративный прокси-сервер и дашборд для контроля, аналитики и оптимизации расходов на API нейросетей (OpenAI, Anthropic и др.).

## Какую проблему мы решаем?
1. **Бесконтрольные траты и "Слепая зона":** Компании закупают доступ к ИИ, но не видят, кто конкретно и сколько тратит.
2. **"Мертвые души":** Оплата доступа для сотрудников, которые им не пользуются.
3. **Безопасность и утечки:** Риск случайной публикации корпоративного API-ключа (Master-Key) на GitHub, что может привести к потере тысяч долларов за ночь.

## Как это работает (Шаг за шагом)

Система работает как прозрачный шлюз (Gateway) между вашими сотрудниками и провайдером ИИ.

1. **Изоляция ключей:** Сотрудники получают *виртуальные внутренние ключи*, сгенерированные нашей системой, а не реальные ключи от OpenAI.
2. **Перехват запроса:** Сотрудник делает обычный запрос к нейросети, но направляет его на наш прокси-сервер.
3. **Проверка доступа:** Сервер проверяет виртуальный ключ в базе данных, валидирует статус пользователя и его лимиты.
4. **Подмена ключа:** Внутренний ключ подменяется на реальный корпоративный API-ключ (Master-Key), который безопасно хранится на сервере.
5. **Запрос к ИИ:** Прокси пересылает запрос к провайдеру (например, OpenAI) и дожидается ответа.
6. **Калькуляция стоимости:** Система парсит ответ, извлекает количество потраченных токенов (входных и выходных) и на основе актуальных тарифов рассчитывает точную стоимость запроса в долларах (USD).
7. **Логирование:** Метаданные (кто, когда, сколько потратил) асинхронно записываются в базу данных без сохранения самих промптов (Privacy First).
8. **Возврат ответа:** Исходный ответ от нейросети возвращается сотруднику.

## Архитектура и безопасность

*   **Zero Master-Key Exposure:** Реальные API-ключи никогда не покидают сервер и хранятся в защищенном окружении (переменные окружения).
*   **Моментальный Quarantine:** В случае компрометации внутреннего ключа, администратор отключает его в дашборде в 1 клик. Все запросы по этому ключу мгновенно блокируются.
*   **Конфиденциальность (Data Sanitization):** Мы храним только финансовые логи. Коммерческая тайна и тексты запросов не оседают в наших базах.

## Стек технологий (Гибрид)

*   **Бэкенд (Proxy API):** Python, FastAPI, `httpx` (для асинхронных запросов).
*   **База данных:** Supabase (PostgreSQL).
*   **Фронтенд (Дашборд):** React (Vite), TailwindCSS, `supabase-js`.

## Локальный запуск (MVP)

### 1. База данных (Supabase)
Создайте проект в Supabase и выполните SQL-скрипт для создания таблиц `users` (сотрудники с их внутренними ключами) и `api_logs` (история запросов и их стоимости).

### 2. Запуск Бэкенда (FastAPI)
```bash
# Перейдите в папку бэкенда, создайте виртуальное окружение и установите зависимости
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
pip install fastapi uvicorn httpx supabase

# Создайте файл .env с ключами SUPABASE_URL, SUPABASE_KEY, OPENAI_API_KEY
uvicorn main:app --reload
```

### 3. Запуск Фронтенда (React)
```bash
# Перейдите в папку фронтенда и установите зависимости
npm install

# Создайте файл .env с вашими переменными VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY
npm run dev
```
